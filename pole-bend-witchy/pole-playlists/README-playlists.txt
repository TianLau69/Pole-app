# Playlists

Copier :
- playlists.html -> racine de pole-bend-witchy/
- js/playlists.js -> pole-bend-witchy/js/

Puis ajouter dans index.html :
<button onclick="location.href='playlists.html'">🎵 Mes playlists</button>

La page utilise :
- pole_custom_exercises pour les exercices ajoutés
- pole_figures pour les figures
- pole_playlists pour les playlists

Pour les exercices de base, data/programs.js doit exposer `PROGRAMS` ou `programs`.
