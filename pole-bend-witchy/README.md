# Programme Pole — Witchy Edition

Refonte graphique sombre / witchy, prête pour GitHub Pages et Codespaces.

## Installation
1. Décompresse le ZIP.
2. Glisse tout le contenu du dossier `pole-bend-witchy` dans ton dépôt GitHub.
3. Dans Codespaces : `python3 -m http.server 8000`, puis ouvre le port 8000.

## Images
La banque contient 38 images d’exercice + 1 image d’accueil. Les JPG fournis sont des **placeholders** : remplace-les par tes photos en conservant exactement les mêmes noms.

**Format recommandé : JPG 1080 × 1350 px (4:5).** Pour rester léger : environ 150 Ko à 800 Ko par image.
